# Road Connectivity in Northern Canada

**Replication and extension · Causal inference · Spatial econometrics · GIS**

This repository contains the reproducible workflow for a replication and extension of research on how road connectivity affects socioeconomic outcomes in Northern Canada.

## Research Question

How does improved road connectivity affect employment, education, and local economic outcomes in remote and Northern communities?

## Empirical Design

The project reconstructs a longitudinal municipality-level panel across Canadian Census waves and combines geographic harmonization with transportation-network exposure measures.

**Methods:** `TWFE` · `Staggered DiD` · `Callaway & Sant'Anna` · `Event Studies` · `GIS Buffers` · `Network Exposure`

## Repository Structure

- `notebooks/` — exploratory analysis and replication notebooks
- `src/` — reusable data-processing and estimation code
- `data/` — documentation for source data and derived datasets
- `figures/` — reproducible figures and maps

## Status

**Work in progress.** The public repository is being organized as a reproducible research package. Data files are not committed until redistribution and licensing conditions are verified.
