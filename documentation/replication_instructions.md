# Replication Instructions

1. Obtain the source data described in `data/README.md`.
2. Place permitted raw inputs under `data/raw/`.
3. Create the computational environment listed in `requirements.txt`.
4. Run `code/00_master.py` once the numbered scripts are complete.
5. Reproduced tables, figures, and logs will be written to `output/`.

Do not commit restricted or non-redistributable source data.
